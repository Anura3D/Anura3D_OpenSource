================================================================================
  APIC/FLIP BLEND FACTOR - CPS INPUT EXAMPLE
================================================================================

This file shows how to add the APIC/FLIP blend factor to your CPS input file.

LOCATION IN CPS FILE:
--------------------
Add this parameter in the "MPM SPECIFIC DATA" section, after $$DEGREE_OF_FILLING
and before $$NUMBER_OF_ACTIVE_ELEMENTS.

SYNTAX:
-------
$$APIC_FLIP_BLEND_FACTOR
<value>

Where <value> is a real number between 0.0 and 1.0:
  - 0.0 = Pure FLIP (minimal dissipation, can be noisy)
  - 1.0 = Pure APIC (more stable, slightly more dissipative)
  - 0.95 to 0.99 = Recommended range for most simulations


EXAMPLE CPS SNIPPET:
--------------------

! ... previous CPS entries ...

! MPM SPECIFIC DATA
$$APPLY_OBJECTIVE_STRESS
1
$$DEGREE_OF_FILLING
0.9
$$APIC_FLIP_BLEND_FACTOR
0.99
$$NUMBER_OF_ACTIVE_ELEMENTS
0

! ... rest of CPS file ...


COMPLETE EXAMPLES BY PROBLEM TYPE:
-----------------------------------

1. SLOPE STABILITY / GEOTECHNICAL (default, maximum stability):
   $$APIC_FLIP_BLEND_FACTOR
   0.99

2. GRANULAR FLOW / LANDSLIDE (balanced):
   $$APIC_FLIP_BLEND_FACTOR
   0.95

3. HIGH-VELOCITY IMPACT (reduced dissipation):
   $$APIC_FLIP_BLEND_FACTOR
   0.90

4. FLUID-LIKE BEHAVIOR (minimal dissipation):
   $$APIC_FLIP_BLEND_FACTOR
   0.50

5. REVERT TO ORIGINAL PIC METHOD:
   $$APIC_FLIP_BLEND_FACTOR
   1.0


DEFAULT BEHAVIOR:
-----------------
If $$APIC_FLIP_BLEND_FACTOR is NOT specified in the CPS file, 
the code uses the default value of 0.99 (99% APIC, 1% FLIP).


VALIDATION:
-----------
Valid values: 0.0 <= α <= 1.0
The code will check this constraint and give an error if violated.


ERROR MESSAGES:
---------------
If you see:
  "CPS file: $$APIC_FLIP_BLEND_FACTOR must be greater than or equal to 0.0"
  "CPS file: $$APIC_FLIP_BLEND_FACTOR must be less than or equal to 1.0"

Check that your value is in the valid range [0.0, 1.0].


REFERENCES:

  - QUICK_START_APIC_FLIP.md (quick start guide)

NOTES:
------
- This parameter only affects MPM computations (not FEM)
- Memory cost: ~72 bytes per particle
- Performance impact: ~10-15% increase in convective phase computation time
- Backward compatible: existing simulations will use the default α=0.99
