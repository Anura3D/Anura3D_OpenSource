SCENARIO 1: USING DEFAULT VALUE
  ┌────────────────────────────────────────────────────────────────────┐
  │ 1. Open GiD project                                                │
  │ 2. Navigate to Calculation_Data                                    │
  │ 3. See "APIC/FLIP blend factor [-]" showing 0.99                  │
  │ 4. Leave as default (recommended for most cases)                   │
  │ 5. Click "Generate" → creates CPS with α=0.99                     │
  └────────────────────────────────────────────────────────────────────┘

SCENARIO 2: CHANGING VALUE FOR GRANULAR FLOW
  ┌────────────────────────────────────────────────────────────────────┐
  │ 1. Navigate to "APIC/FLIP blend factor [-]" field                 │
  │ 2. Click in the input box                                          │
  │ 3. Delete current value (0.99)                                     │
  │ 4. Type new value: 0.95                                            │
  │ 5. Press Enter or Tab to confirm                                   │
  │ 6. Click "Generate" → creates CPS with α=0.95                     │
  └────────────────────────────────────────────────────────────────────┘

SCENARIO 3: CHECKING HELP TEXT
  ┌────────────────────────────────────────────────────────────────────┐
  │ 1. Locate "APIC/FLIP blend factor [-]" field                      │
  │ 2. Hover mouse over field label or (?) icon                       │
  │ 3. Read tooltip explaining parameter                               │
  │ 4. Note recommended range: 0.95-0.99                               │
  │ 5. Choose appropriate value for your problem type                  │
  └────────────────────────────────────────────────────────────────────┘

BEFORE (Manual CPS Editing):
  ┌────────────────────────────────────────────────────────────────────┐
  │ 1. Generate CPS file from GiD                                      │
  │ 2. Close GiD                                                        │
  │ 3. Open .CPS file in text editor                                   │
  │ 4. Find $$DEGREE_OF_FILLING section                                │
  │ 5. Manually type:                                                   │
  │    $$APIC_FLIP_BLEND_FACTOR                                         │
  │    0.95                                                             │
  │ 6. Save file carefully (don't break format!)                       │
  │ 7. Run simulation                                                   │
  │                                                                     │
  │ Pros: Direct control                                                │
  │ Cons: Error-prone, tedious, easy to forget                         │
  └────────────────────────────────────────────────────────────────────┘

AFTER (GUI Input) - MUCH EASIER!:
  ┌────────────────────────────────────────────────────────────────────┐
  │ 1. Open project in GiD                                             │
  │ 2. Navigate to Calculation_Data                                    │
  │ 3. Change "APIC/FLIP blend factor" to 0.95                        │
  │ 4. Click "Generate"                                                 │
  │ 5. Run simulation                                                   │
  │                                                                     │
  │ Pros: Easy, visual, guided, no manual editing                      │
  │ Cons: Requires GiD (but you're using it anyway!)                   │
  └────────────────────────────────────────────────────────────────────┘

PROBLEM: Field doesn't appear in GiD
  ┌──────────────────────────────────────────────────────────────────┐
  │ Check:                                                            │
  │  □ Using Anura3D_2025 problem type?                              │
  │  □ CalculationData.xml file updated?                             │
  │  □ GiD restarted after update?                                   │
  │  □ Looking in correct section (Calculation_Data)?                │
  │                                                                   │
  │ Solution: Close GiD, verify XML file, restart GiD                │
  └──────────────────────────────────────────────────────────────────┘

PROBLEM: Value doesn't appear in CPS file
  ┌──────────────────────────────────────────────────────────────────┐
  │ Check:                                                            │
  │  □ Clicked "Generate" after changing value?                      │
  │  □ createCPS.tcl script updated?                                 │
  │  □ Looking at correct .CPS file (not old version)?               │
  │  □ Check TCL console for error messages                          │
  │                                                                   │
  │ Solution: Regenerate files, check script, verify file location   │
  └──────────────────────────────────────────────────────────────────┘

PROBLEM: Simulation ignores value
  ┌──────────────────────────────────────────────────────────────────┐
  │ Check:                                                            │
  │  □ Using updated Anura3D executable?                             │
  │  □ CPS file contains $$APIC_FLIP_BLEND_FACTOR?                   │
  │  □ Value is numeric (not text)?                                  │
  │  □ Check console output for parameter reading                    │
  │                                                                   │
  │ Solution: Recompile code, verify CPS format, check output        │
  └──────────────────────────────────────────────────────────────────┘
