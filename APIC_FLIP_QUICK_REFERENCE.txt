┌─ CPS FILE SYNTAX ──────────────────────────────────────────────────────────┐
│                                                                             │
│  $$APIC_FLIP_BLEND_FACTOR                                                  │
│  0.99                                                                       │
│                                                                             │
│  Place in: MPM SPECIFIC DATA section (after $$DEGREE_OF_FILLING)          │
│  Range: 0.0 ≤ α ≤ 1.0                                                      │
│  Default: 0.99 (if not specified)                                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ WHAT DOES IT DO? ─────────────────────────────────────────────────────────┐
│                                                                             │
│  Controls the blend between two velocity transfer methods:                 │
│                                                                             │
│    v_new = α × v_APIC + (1-α) × v_FLIP                                     │
│                                                                             │
│  • α = 1.0 → Pure APIC (stable, slightly dissipative)                      │
│  • α = 0.0 → Pure FLIP (minimal dissipation, can be noisy)                 │
│  • α = 0.99 → Recommended (best balance for most cases)                    │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ RECOMMENDED VALUES BY PROBLEM TYPE ───────────────────────────────────────┐
│                                                                             │
│  Problem Type              │  α Value  │  Notes                             │
│  ─────────────────────────────────────────────────────────────────────────  │
│  Geotechnical / Slopes     │   0.99    │  Maximum stability (default)       │
│  Granular flows            │   0.95    │  Balanced dissipation/accuracy     │
│  Impact / Penetration      │   0.90    │  Reduced dissipation               │
│  Fluid-like behavior       │   0.50    │  Minimal dissipation (advanced)    │
│  Debug / Compare to old    │   1.00    │  Pure APIC (original PIC)          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
